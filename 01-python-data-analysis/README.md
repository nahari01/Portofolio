# Python Data Analysis – Sales Performance

## Objective
Menganalisis performa penjualan untuk mengidentifikasi tren,
penurunan performa, dan faktor yang memengaruhinya.

## Dataset
Dataset penjualan retail (±50.000 data, 2021–2023).

## Tools
- Python (Pandas, NumPy)
- Jupyter Notebook

## Analysis Steps
1. Data understanding
2. Data cleaning
3. Exploratory Data Analysis
4. Insight & interpretation

## Key Insights
- Penjualan menurun pada Q3 sebesar ±18%
- Wilayah Timur memiliki performa terendah

## Recommendations
- Optimalisasi strategi promosi di Q3
- Evaluasi distribusi wilayah Timur
