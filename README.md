# Data Analyst Portfolio – Nahari Ihsan

Repository ini berisi kumpulan project Data Analyst yang menunjukkan kemampuan
dalam pengolahan data, analisis data, dan visualisasi data untuk menghasilkan
insight yang mendukung pengambilan keputusan berbasis data.

## Technical Skills
- **Python**: Pandas, NumPy (data cleaning, exploratory data analysis)
- **SQL**: SELECT, JOIN, WHERE, GROUP BY (data querying & aggregation)
- **Microsoft Excel**: Pivot Table, VLOOKUP (data processing & reporting)
- **Data Visualization**: Power BI, Tableau (dashboard & visual analytics)
- **Tools Pendukung**: KNIME, Jupyter Notebook

## Portfolio Structure
Portofolio ini dibagi berdasarkan kemampuan teknis utama sebagai berikut:
1. Python Data Analysis
2. SQL Data Analysis
3. Excel Data Processing
4. Dashboard Visualization (Power BI / Tableau)

Setiap project dilengkapi dengan penjelasan tujuan analisis, dataset yang
digunakan, proses pengolahan data, insight utama, serta rekomendasi berbasis data.

## Objective
Tujuan dari portofolio ini adalah untuk menunjukkan kemampuan praktis dalam
mengolah data mentah menjadi informasi yang bernilai serta menyajikan hasil
analisis secara terstruktur dan mudah dipahami oleh stakeholder.
